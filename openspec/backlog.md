## Внешние зависимости и риски

Сервисы автора `*.nakarte.me` отключены (`drop-author-services`), но клон зависит от чужих сервисов, которые могут сломаться без нашего участия. Список — чтобы при поломке сразу знать, что отвалилось и что уже есть на этот случай. Сверено по коду 2026-10-08. Пункты с отдельной записью ниже здесь только названы.

- CheerpJ (`cjrtnc.leaningtech.com/4.3/loader.js`, `routingEngineRuntimeUrl` в `web/src/config.ts`): рантайм движка в браузере грузится с CDN Leaning Technologies. Упадёт CDN или сменится версия — в клоне не работает прокладка маршрута (серверный режим не затронут). Защиты нет; держать рантайм у себя лицензия Community не позволяет (пункт в «Отложено»). Скрипт грузится без SRI: подмена на CDN — чужой JS на origin клона (security-аудит, п. 6). SRI не поможет (проверено 2026-11-07): в Web Worker загрузчик подключается через `importScripts`, у которого нет `integrity`, а сам `loader.js` тянет остальной рантайм с того же CDN без проверки. Защита — только свой хостинг рантайма, а его лицензия Community не разрешает.
- brouter.de: источник тайлов роутинга (`*.rd5`) и `lookups.dat` для синхронизации по понедельникам. Тайлы лежат в нашем R2, поэтому недоступность brouter.de только останавливает обновление; смена `lookups.dat` роняет синхронизацию. Синхронизация сверяет `lookups.dat` только с brouter.de, а профили и `lookups.dat` движка берутся из образа `brouter:nightly`; 2026-10-08 файлы совпадают побайтно. Образ в деплое закреплён по digest (`BROUTER_IMAGE` в `deploy-pages.yml`), обновление — вручную по комментарию там.
- Strava heatmap: держится на сессии `STRAVA_SESSION`, срок которой неизвестен; без неё — анонимные тайлы до z12, письмо от `strava heatmap check`. Подробности — пункт в «Отложено».
- Google Street View без ключа: против условий Google, режим разработки может закрыться. Пункт про свой ключ — в «Отложено».
- Tracestrack Topo (подложка по умолчанию с change `add-outdoor-basemap` до change `openfreemap-default-basemap`, теперь — вторая в цепочке отката после OpenFreeMap): бесплатный тариф — 100 тыс. тайлов в месяц (≈ 700–2000 заходов), только некоммерческое использование, что при исчерпании — не сказано. Ключ в секрете прокси, но `Origin` подделывается не-браузером, а лимит прокси — на IP, так что квоту можно выбрать снаружи. При отказе приложение откатывается на OSM с тостом, `tracestrack check` присылает письмо. Если квоты не хватит: тариф Personal (€3.99, 250 тыс.), кеш тайлов в Pages Function с Cache API (на `*.workers.dev` Cache API не работает; у Pages Functions на живом `*.pages.dev` не проверено), свой стиль на OpenFreeMap (пункт в «Новые возможности»). Пороги по замерам 2026-10-30 (≈ 900 активных заходов с десктопа в месяц) и варианты — `openspec/research/load-capacity.md`.
- Импорт треков по ссылкам Strava, Garmin Connect и Wikiloc в приложении не делается (решение владельца 2026-10-08, `record-new-ui-decisions`): сервисы режут запросы не из браузера. Strava `activities/<id>/streams` без входа отвечает `301` на `/login`, `401` или `403`; Garmin Connect — `403` от bot management Cloudflare на curl, node fetch и Worker; Wikiloc с 2026-10-07 — JS-челлендж Cloudflare (`403`) на любой запрос не из браузера, на всех хостах и через любой прокси. Если вернуться — импорт через OAuth API Strava и Garmin.
- Tracedetrail ограничивает частоту: через прокси клона ≈ 3 запроса подряд, затем ≈ 30 с `429` (проверено 2026-10-09 из Chromium; последовательный curl проходит). Старый клиент и новое приложение показывают на `429` ошибку сети (`NETWORK`); импорт одного трека не затронут. Сетевые тесты karma tracedetrail из-за этого убраны.
- Лицензии слоёв и поиска: Google и Bing без лицензии, поиск mapy.cz — недокументированная ручка; разбор — `openspec/research/map-layers.md`, «Риски уже подключённого», владелец не решал. С 2026-10-28 Google Map — одно из трёх превью справа (выбор владельца, архив `three-quick-bases`): если тайлы Google закроют, заменить первый код группы в `web/src/layers/quick-layers.ts`, место в `PLACES` скрипта превью и переснять превью.
- EOX Sentinel-2 cloudless (подложка `S2`, архив `add-sentinel-imagery`): бесплатный WMTS `tiles.maps.eox.at` без ключа, без опубликованных лимитов и SLA; лицензия CC BY-NC-SA 4.0 — только некоммерческое использование. Сервис ляжет — слой пустеет; при коммерции — лицензия EOX или снять слой. Не решено: EOX просит подпись «clearly visible» в интерфейсе карты, а атрибуция сворачивается в (i) после движения карты (архив `map-chrome`); превью `S2` удалено (архив `three-quick-bases`), но превью `E` и `G` в `web/src/layers/thumbnails/` — так же куски чужих тайлов в MIT-репозитории без пометки.
- Поиск по названиям: mapy.cz через свой прокси (главный) и photon.komoot.io напрямую как запасной (публичный инстанс Komoot, без ключа и без гарантий). Лягут оба — не работает поиск по названиям; поиск по координатам и ссылкам работает без них.
- Тайловые слои: OSM, OpenTopoMap, CyclOSM, Waymarked Trails, Thunderforest (без ключа; с 2026-10-11 на тайлах водяной знак «API Key Required», владелец оставил как есть), Bing, Google, ESRI, национальные (swisstopo, Kartverket, Lantmäteriet, IGN и др.), слои через прокси (Strava, `Mt`). Ломаются по одному, слой просто пустеет; так же было у автора. Раз в неделю workflow `layer tiles check` запрашивает по тайлу каждого растрового слоя каталога (`scripts/layer-tiles-check.mjs`) и падает с письмом. Первый прогон 2026-11-07: `tiles.slazav.xyz` (`Q`, `Z`) не отвечал — ни напрямую, ни через прокси.
- Sentry (трекер ошибок браузера, change `add-error-tracking`): план Developer — 5 тыс. ошибок в месяц, 1 пользователь, история 30 дней ([sentry.io/pricing](https://sentry.io/pricing/), 2026-10-30); одна массовая ошибка выберет лимит, остальные отчёты Sentry отбросит до конца месяца. DSN публичен (он в бандле): кто угодно может слать в проект мусор — защита только фильтрами и Allowed Domains проекта.
- OpenFreeMap (подложка по умолчанию `Of` с change `openfreemap-default-basemap`): публичный инстанс без лимитов и без SLA, сервис могут закрыть без уведомления ([условия](https://openfreemap.org/tos/)). При сбое — откат на Tracestrack Topo, чья квота кончится за дни долгого простоя, дальше OSM. Откат — не ошибка для Sentry, поэтому сигнал о сбое даёт ежедневная проверка `Of` (TileJSON и тайл) — workflow `openfreemap check`, при сбое GitHub шлёт письмо.

## Отложено

- Strava heatmap: z13–z16 живут, пока жива сессия `STRAVA_SESSION`, а её срок неизвестен: в браузере `_strava4_session` без `Expires`, куки «запомнить меня» нет (`--probe` в `scripts/strava-session-secret.mjs`), и ни одна страница сессию не продлевает: `/dashboard`, `/api/next/session/get`, счётчик уведомлений и heatmap отвечают без `Set-Cookie: _strava4_session` (`--rotation`, 2026-10-08). Срок решает сервер Strava; если он продлевается активностью, его держат ежедневные заходы прокси, срок покажет `strava heatmap check`. Новую сессию даёт только вход человека: вход защищён reCAPTCHA v3 Enterprise на `/login/request_otp` и `/session`, автологин по крону не делаем; удалённый браузер получил бы ту же сессию. Если сессия окажется короткой — расширение Chrome, которое после ручного входа само отправляет новую `_strava4_session` в прокси (KV), чтобы обойтись без скрипта. Условия Strava (сверено 2026-10-10, design архива `map-chrome`, «Условия атрибуции»): о показе heatmap в стороннем приложении молчат, а автоматический доступ и сбор данных запрещают — ежедневные заходы прокси под сессией владельца формально под этот запрет попадают.
- Лицензия CheerpJ Community: держать рантайм у себя нельзя — «Self-Hosting not allowed» для Community, только по коммерческой лицензии ([licensing](https://cheerpj.com/licensing/), 2026-10-08), то есть требование «Рантайм с CDN Leaning Technologies» в `browser-routing-engine` верно. Авторство «Built with CheerpJ» обязательно (сверено 2026-11-07), оно в подписи карты клона (архив `cheerpj-credit`).
- Проверка в Firefox, Safari и на телефоне.
- Свой ключ Google для Street View, если понадобится чистая панорама. Сейчас клон, как nakarte.me, грузит Maps JavaScript API без ключа (`keyless-street-view`) и прячет режим разработки Google своим CSS (`hide-street-view-dev-overlay`); это против условий Google, и Google может режим закрыть или сменить вёрстку. Ключ — секрет GitHub `GOOGLE_MAPS_API_KEY`, деплой подставит его сам. Шаги владельца: проект в Google Cloud с биллингом (карта нужна даже для бесплатного объёма), включить Maps JavaScript API, создать ключ с ограничениями Websites `https://nakarte-routing.pages.dev` и API только Maps JavaScript API ([рекомендации Google](https://developers.google.com/maps/api-security-best-practices)), бюджет с оповещением, `gh secret set GOOGLE_MAPS_API_KEY`. Цена по [прайсу Google Maps Platform](https://developers.google.com/maps/billing-and-pricing/pricing): Dynamic Street View — 5 000 бесплатных панорам в месяц, дальше $14 за 1 000; покрытие — тайлы без ключа, не тарифицируются.

## Данные из ответа BRouter

В `features[0].properties` есть `track-length`, `filtered ascend`, `total-time` и `messages` — таблица по участкам, где колонка `WayTags` содержит `highway=…`, `surface=…`. Параметры запроса: `nogos`, `polylines`, `polygons`, `alternativeidx`, `straight`, `roundTrip*`, `profile:<переменная>`. Через `profile:` переопределяется любая `assign`-переменная профиля, даже без пометки `%…%`.

Покрыть, когда раскладка устоится.
- Сводка профиля — средний и наибольший уклон в градусах (спека `tracks`, «Сводка профиля», как у старого клиента), а легенда и курсор — в процентах (архив `slope-profile`). Перевести сводку в проценты, если две единицы начнут путать.
- Пока линия редактируется, верхняя строка — редактор, и списка треков не открыть: имя, цвет и экспорт — в строке редактора (архивы `editor-name-share` и `editor-row-cleanup`), а видимость других треков, дублирование и удаление — после `Finish editing`. Вернуть доступ к списку, только если это начнёт мешать: место — главное.
- Alt+L не ставит курсор в поиск, пока линия редактируется или ставятся точки: верхняя строка занята их панелью, а введённый запрос теряется (спека `map-search`, «Строка поиска»). Так же во время правки не вставить ссылку на трек: она теперь только в поиске (архив `search-track-links`), а поля `Track URL` тогда не было видно и раньше.
- Диалоги Configure layers и Add custom layer в макете не отрисованы полностью — вид прежний, со стеклом темы.

## Новые возможности

- Векторная подложка OpenFreeMap Outdoor (`Of`) — подложка по умолчанию с откатом на `Tt` и OSM (архивы `add-vector-outdoor-style` и `openfreemap-default-basemap`): свой стиль, подписи «местное / язык браузера или латиница» на любом зуме. Значки хижин, приютов, кемпингов, воды и смотровых сделаны без спрайта (архив `outdoor-poi-icons`). Рельеф `Hs` рисуется внутри стиля, под водой, дорогами и подписями (архив `outdoor-relief-in-style`). Дальше: свой хостинг тайлов — та же схема OpenMapTiles через Planetiler в PMTiles на R2, если OpenFreeMap закроется (ресёрч `openspec/research/new-ui.md`, «Рекомендация на потом»).
- Слои Яндекса (`Y` карта, `S` спутник) в новом UI на MapLibre: Яндекс отдаёт тайлы в EPSG:3395, MapLibre рисует растр только в Web Mercator. Вариант — перепроекция в браузере через `addProtocol`: склеивать два тайла Яндекса со сдвигом по вертикали, как `_adjustHeight` старого клиента (`git show 015be893:src/lib/leaflet.layer.yandex/index.js`); около дня. В первой версии нового UI их нет (решение владельца 2026-10-08, `record-new-ui-decisions`).
- Отправка маршрута прямо в приложение часов и велокомпьютера — COROS, Wahoo, Garmin (запрос пользователя, переданный владельцем 2026-10-12): ресёрч сделан 2026-10-12 — [`openspec/research/device-route-sync.md`](research/device-route-sync.md), там же решения владельца и changes. Файловый путь — «Save as GPX» с высотами: окно «Send to device» сделано ([архив `send-route-to-device`](changes/archive/2026-10-12-send-route-to-device/design.md)) и удалено владельцем 2026-10-29 ([архив `trim-track-menus`](changes/archive/2026-10-29-trim-track-menus/design.md)). ## Варианты движка в браузере

Выбран CheerpJ. Замеры CheerpJ 4.3 (2026-10-06): 10 км — 0.3–0.55 с на прогретом движке, сервер в 3–4 раза быстрее; холодный старт ≈ 5–6 с; 0.6–0.8 ГБ RSS на вкладку. В Web Worker (2026-10-08, change `spike-engine-in-worker`) главный поток свободен, движок — ≈ 0.3–0.5 ГБ `phys_footprint`; RSS на macOS эту цифру занижает, а старые 0.6–0.8 ГБ — оценка по RSS другого стенда. Остальное — на случай, если упрёмся в его слабые места. Цена — грубая оценка, риск — то, что может убить вариант.

| Вариант | Суть | Что известно | Цена | Главный риск |
|---|---|---|---|---|
| CheerpJ | JVM в Wasm, гоняет jar BRouter как есть | работает, замерено | интеграция: дни | память, холодный старт, чужой CDN и лицензия |
| BeeRouter → `wasmJs` | форк BRouter на Kotlin Multiplatform (MPL-2.0), те же `.brf`, `.rd5`, `lookups.dat`; добавить таргет Kotlin/Wasm | сейчас собирается только `jvm` и `linuxX64`, зависимости публикуют `js` и `wasmJs`; чтение данных идёт через синхронный `RandomAccessReader` | спайк: 1–3 дня | под wasm никто не собирал; молодой проект, 0.0.6 |
| TeaVM | AOT-компиляция Java BRouter в Wasm GC или JS | аудит по коду: 2 класса правок, синхронное чтение тайлов внутри A* | PoC 1–2 дня, рабочая версия 5–9 | скорость A* не мерена, подмена ФС через внутренний API |
| Kotlin-порт из `stefanhoelzl/tracks` | ядро BRouter 1.7.10 переведено J2K, паритет с brouter.de побайтно (MIT) | прецедент и тест-методика; таргеты jvm, linuxX64, iOS | как у BeeRouter | нашли тихие расхождения `(int) x` и `float += double` |
| Другие компиляторы Java → Wasm | GraalVM Web Image, J2CL/J2Wasm, Bytecoder, JWebAssembly | GraalVM экспериментальный: ФС только в памяти, потоков нет; J2CL без `File` и `RandomAccessFile`; остальные заморожены | — | не годятся без переделки I/O |
| Переписать ядро на Rust | свой движок, совместимый с `.rd5` и `.brf`, через `wasm-bindgen` | готового порта нет ни на одном языке; A* и обвязка есть в крейтах; дорогие части — язык `.brf` и кодек `.rd5` | недели: ~18 тыс. строк Java в core, mapaccess, expressions, codec, util | паритет с BRouter (float, округления), объём |
| Переписать ядро на TS | то же, но на JS | как у Rust; `float` эмулируется через `Math.fround` | как у Rust | скорость A* в JS |
| Valhalla в Wasm | `tobilg/valhalla-wasm`: готовый движок, тайлы `.gph` по Range | работает, wasm 9.9 МБ, есть `bicycle` и `pedestrian` с `sac_scale` | своя сборка и раздача тайлов, переписать активности | другой движок и данные, высот в графе нет |
| Экзотика | граф из векторных тайлов OpenMapTiles или PMTiles, SQLite по HTTP Range, DuckDB-Wasm | готового роутинга нет; в OMT теряется топология и нет высот; DuckDB умеет только невзвешенный путь | исследование | всё |

Не существует: OSRM в Wasm, pgRouting в PGlite, современный GraphHopper в браузере.

Параллельный расчёт отрезков: у каждого Web Worker свой экземпляр CheerpJ (проверено в `spike-engine-in-worker`), поэтому несколько воркеров считали бы отрезки одновременно. Цена — ≈ 0.3–0.5 ГБ и холодный старт на воркер; сейчас движок один на страницу, очередь из быстрых кликов проходит за секунды. Вернуться, если длинные маршруты из многих отрезков станут ждать заметно.
