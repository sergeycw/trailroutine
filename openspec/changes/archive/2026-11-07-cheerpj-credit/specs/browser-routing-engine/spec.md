## ADDED Requirements

### Requirement: Built with CheerpJ credit

The clone build SHALL show «Built with CheerpJ» with a link to `https://cheerpj.com/` and the BRouter credit in the map attribution, as the CheerpJ Community license requires. A build with the server BRouter SHALL NOT show it.

#### Scenario: Credit in the attribution

- **WHEN** the clone build opens and the user expands the map attribution
- **THEN** it has «Routing BRouter · Built with CheerpJ» with the two links next to the layer attribution
